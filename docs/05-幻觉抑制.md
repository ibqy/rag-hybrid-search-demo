# 五、幻觉抑制：引用有效不等于事实成立

## 当前能力与边界

> 源码：[hallucination 包](../src/main/java/com/xb/rag/hallucination/)。

仓库包含约束 Prompt、引用编号检查和可选模型自检。它们可以作为回答校验的教学组件，但没有经过独立答案数据集验证，不能宣称达到某个幻觉率或生产准确率。

当前问答逻辑是：

```text
混合检索 → 空结果则拒答
        → 非空结果构建上下文 → 模型回答
        → 可选模型自检 → 引用校验 → 返回
```

这不是“Rerank + 阈值过滤 + 完整安全校验”链路：控制器未调用 Rerank，也没有应用其 0.45 阈值。

## 三类校验分别回答什么

### 1. 约束 Prompt：表达任务要求

[PromptConstants](../src/main/java/com/xb/rag/hallucination/PromptConstants.java) 要求根据参考资料回答、标注来源，并在缺乏信息时拒答。Prompt 是行为引导，不是事实证明或权限机制。

检索文档属于不可信数据，可能包含与任务无关的指令。实际接入时应明确区分系统规则与检索内容，并针对文档中伪造指令做测试；本仓库没有完整的提示注入防护证明。

### 2. 引用校验：编号能否定位来源

[CitationValidator](../src/main/java/com/xb/rag/hallucination/CitationValidator.java) 检查 `[N]` 是否在可用来源编号范围内。它不能单凭编号判断来源是否支持对应句子。

**示意**：片段 `[1]` 写着“试用期为 7 天”，回答却说“试用期为 30 天 [1]”。编号有效，事实仍然错误。去掉无效的 `[99]` 也不会自动修复它前面的错误断言。

还应分别检查：

- 有事实断言却没有引用。
- 引用存在但版本过期、正文被截断或不能定位原文。
- 一句话包含多个事实，只引用了支持其中一个的片段。

这些需要事实级支持判断，不是当前编号检查器的保证。

### 3. 模型自检：辅助信号，不是人工真值

[HallucinationDetector](../src/main/java/com/xb/rag/hallucination/HallucinationDetector.java) 再调用模型，对回答与参考资料作比较并解析文本结果。额外调用意味着延迟、成本及新的失败点；同类模型也可能重复同一种错误。

当前异常分支会标记疑似问题，但自由文本解析仍可能误判；模型给出的 confidence 不能当作校准后的真实概率。应区分“发现不支持的事实”“检测失败”“没有执行检测”，而不是都压缩为一个质量结论。

API 的 `enableHallucinationCheck` 默认 false；未运行自检时 `hasHallucination` 也为 0，**不表示回答已通过事实审计**。

## 空结果拒答不是完整的拒答策略

当前控制器在检索列表为空时拒答。列表非空却可能只有无关、冲突或过期证据；不能把“有返回值”当成“有答案”。RRF 分数是相对排名，不是可直接设阈值的回答可信度。

需要在独立无答案集上评估拒答：语料确实没有信息、只有部分信息、版本冲突、诱导虚构引用等情况。不要把这些无相关标签的问题硬塞进要求非空相关集合的排名评估器。

## 实践：建立答案支持矩阵

这是待执行的答案评测方法，不是 `EvalRunner` 现有指标：

| 记录项 | 人工核查问题 |
|---|---|
| 问题与上下文快照 | 当时模型实际看到了哪些片段？ |
| 答案中的原子事实 | 每个数字、条件、例外能否单独核查？ |
| 支持证据 | 哪段原文支持该事实，是否同一版本？ |
| 引用正确性 | 编号能定位且内容真正蕴含该断言吗？ |
| 完整性与拒答 | 是否漏掉关键条件；证据不足时是否明确说明？ |
| 自检结果 | 与人工判断在哪些类型上不一致？ |

固定生成模型、Prompt、上下文预算和标签，在验证集确定接受标准，再在未参与调参的测试集核验。目标应由业务后果和标注协议决定，不使用任意的“幻觉率小于 5%”口号。

## 与排名评测的关系

[第 07 章](./07-RAG评估体系.md) 只计算 Recall@K、Precision@K、MRR@K、二值 nDCG@K。它不生成答案，不用 `expectedAnswer` 评分，也不计算幻觉率。

- 证据没找到：先查解析、分块、召回和标签。
- 证据找到了却答错：查上下文排序/截断、Prompt、生成与事实支持。
- 自检说正确但人工判错：查裁判偏差，不能拿自检结果作唯一真值。

官方参考：[Spring AI RAG](https://docs.spring.io/spring-ai/reference/api/retrieval-augmented-generation.html)。框架提供组件不等于应用自动获得完整的质量与安全保证。

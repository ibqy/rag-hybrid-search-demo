# 一、文档预处理：先检查证据有没有留下

## 为什么先看解析，而不是先换模型

检索无法找回从未进入 chunk 的证据。表格列错位、页眉混入、扫描文字漏提和清洗误删，都会表现为“回答不准”，但不是改 Prompt 就能解决的问题。

> 源码：[document 包](../src/main/java/com/xb/rag/document/)。当前上传入口做解析与分块，不产生可搜索的索引写入。

```text
文件 → 类型识别 → 解析为 DocSegment + DocumentMeta
     → 清洗 → ParseResult → 后续分块
```

解析器接口返回 `ParseResult`，其中包含段落、元数据及成功/错误信息。不要把返回了一个对象等同于解析成功。

## 解析器及真实边界

| 输入 | 源码 | 实现思路 | 需要检查的边界 |
|---|---|---|---|
| PDF | [PdfParser](../src/main/java/com/xb/rag/document/parser/PdfParser.java) | PDFBox 逐页提取；按相对 Y 坐标过滤页眉页脚；空格分列的表格启发式 | 双栏顺序、旋转页、跨页表格、边缘正文误删；不是完整版面理解 |
| DOCX | [WordParser](../src/main/java/com/xb/rag/document/parser/WordParser.java) | 段落样式与标题栈、表格转换 | 自定义样式、合并单元格、图片和页码定位；不能保证所有 Word 文档结构无损 |
| Markdown | [MarkdownParser](../src/main/java/com/xb/rag/document/parser/MarkdownParser.java) | 正则识别标题与 fenced code，用占位符避免代码内 `#` 被当标题 | 不是完整 Markdown AST；检查代码重复、正文顺序与无标题内容 |
| OCR | [OcrService](../src/main/java/com/xb/rag/document/parser/OcrService.java) | Tess4J 封装 | 需要本机 Tesseract / 语言数据；PDF 解析器没有自动串接 OCR 补全扫描页 |

扩展名能被识别，不代表已有对应解析器被注册。接入新类型前，检查 `DocumentProcessor` 的类型路由与实际解析器集合。

## 清洗是有损变换

[DocCleaner](../src/main/java/com/xb/rag/document/cleaner/DocCleaner.java) 包括页眉/页脚模式、目录识别、重复行移除与空白标准化。规则简单可读，但不理解语义。

- 删除版权行可能误删真正讨论版权的证据。
- 重复行可能是表格里的合法重复值，而不一定是噪声。
- 压缩空格可能破坏代码缩进或依赖空格的表格布局。
- 全角转半角适合部分搜索归一化，但原始引用仍需可追溯。

建议保留原始文本与清洗后文本的对照，按 `contentType` 制定保护策略；当前通用清洗不能直接当作所有表格、代码的无损处理器。

## 元数据：可追溯与权限是两件事

- 文档层：`docId`、文档名、来源、指纹与版本信息。
- 段落/chunk 层：所属文档、页码、章节、内容类型及源段落位置。
- 权限层：`tenantId` / 角色等字段只有被写入并在两路检索前执行过滤，才构成隔离。

**当前问答控制器没有使用 tenantId 过滤。** 元数据字段存在不等于权限系统已实现。PDF 页码、DOCX 的未知页码及聚合后的页码也应区别展示，不应制造精确定位的假象。

## 实践：做一组解析验收样本

以下是建议的人工/自动化验收方法，不是仓库已经覆盖所有格式的测试声明。

1. 选择带页眉的 PDF、扫描 PDF、含表格的 DOCX、含代码与多级标题的 Markdown。
2. 为每个文件圈定几个必须保留的证据：一条编号、一段流程、一行表格和一处标题关联。
3. 比较原文、解析段落、清洗文本、最终 chunk；记录每一步证据是否丢失或重复。
4. 检查解析失败与“成功但内容为空”是否有独立状态；不要让空 chunk 统计掩盖故障。
5. 冻结文件哈希和处理规则版本，再进入检索评测。

| 观察到的问题 | 优先检查 |
|---|---|
| 整个扫描页没有文字 | 是否真的调用了 OCR，而不是只配置 Tess4J 依赖 |
| 表格命中但数值对应错误 | 列关系是否在解析/清洗时丢失 |
| 代码命中多次 | 占位符恢复与独立 code segment 是否重复输出 |
| 引用找不到原文 | 文档版本、页码及 segment → chunk 映射是否保留 |

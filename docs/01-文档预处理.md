# 一、文档预处理（RAG 效果基石）

## 问题背景

基础 RAG 只用 Tika 提取纯文本，表格结构丢失、图片文字漏提、页眉页脚混入正文。这些噪声直接影响后续切片质量和检索效果。

## 本模块职责

> 源文件：[document 包](../src/main/java/com/xb/rag/document/)

```
多类型文档 → 结构化解析 → 清洗降噪 → 元数据绑定 → 输出干净切片
```

## 核心设计

### 1. 多类型文档解析器

| 文档类型 | 解析器 | 策略 |
|---------|--------|------|
| PDF | [`PdfParser.java`](../src/main/java/com/xb/rag/document/parser/PdfParser.java) | PDFBox 提取文本 + 按 Y 坐标过滤页眉页脚；表格启发式检测转 Markdown |
| DOCX | [`WordParser.java`](../src/main/java/com/xb/rag/document/parser/WordParser.java) | docx4j 遍历段落，维护标题层级栈，表格整体输出 |
| Markdown | [`MarkdownParser.java`](../src/main/java/com/xb/rag/document/parser/MarkdownParser.java) | 解析标题树，代码块占位符保护防止被切碎 |
| 图文混排 | [`OcrService.java`](../src/main/java/com/xb/rag/document/parser/OcrService.java) | Tess4J 封装，PDF 图片区域 OCR 提取 |

所有解析器实现 [`DocumentParser`](../src/main/java/com/xb/rag/document/parser/DocumentParser.java) 接口，统一返回 `List<DocSegment>`。

### 2. 文档清洗降噪

[`DocCleaner.java`](../src/main/java/com/xb/rag/document/cleaner/DocCleaner.java) 静态工具类：
- 去除页眉页脚、页码、水印、目录
- 全角/半角转换
- 去除重复段落
- 压缩多余空白换行

### 3. 元数据体系

[`DocumentMeta.java`](../src/main/java/com/xb/rag/document/DocumentMeta.java) 绑定每条 chunk 的元数据：

```
docId, docName, sourcePath, pageNum, sectionTitle, headingLevel
tenantId, visibleRoles → 检索时行级权限过滤
md5 → 增量更新变更检测
contentType: text / table / code / ocr
```

### 4. 编排入口

[`DocumentProcessor.java`](../src/main/java/com/xb/rag/document/DocumentProcessor.java) 统一编排：
- 识别文档类型 → 匹配解析器 → 解析切片 → 清洗 → 计算 MD5 指纹

## 面试要点

- 为什么页眉页脚不能进向量库？检索时返回的片段包含页码/水印，降低质量
- Metadata 过滤如何提升召回精度？检索前先按 tenantId 过滤，缩小范围
